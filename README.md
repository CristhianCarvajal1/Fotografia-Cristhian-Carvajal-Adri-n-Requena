# Cristhian Carvajal y Adrian Requena — Webzine de Fotografía

Proyecto para abrir directamente en Visual Studio Code.

## Estructura

- index.html
- css/style.css
- img/

## Fotografías

Coloca tus fotografías dentro de `img` usando estos nombres:

foto1.jpg
foto2.jpg
foto3.jpg
foto4.jpg
foto5.jpg
foto6.jpg
foto7.jpg

No se usan librerías externas ni frameworks.

## Abrir

1. Extrae el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en el navegador.

El diseño utiliza HTML5 semántico, CSS Grid, Flexbox, formularios, pseudoclases y media queries, siguiendo el material entregado para el taller.
